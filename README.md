# Универсальный ИИ-бот для Telegram

## Что умеет
- **Единая память** — вся история диалога хранится в SQLite (`memory.db`), переживает
  перезапуск бота. Чат, генерация Excel и картинок пишут и читают из ОДНОЙ истории —
  поэтому любая модель "видит" контекст, даже если до неё отвечала другая.
- **Ротация моделей** — несколько моделей на провайдера (сейчас 3 Gemini + 2 Mistral +
  1 GPT-OSS), роутер перебирает их по очереди, пока одна не ответит успешно
- Распознавание голосовых сообщений (через Gemini, тоже с перебором моделей)
- Генерация картинок по тексту (через Gemini)
- Генерация Excel-таблиц по запросу ("сделай таблицу...", "посчитай..."), с учётом
  предыдущего контекста диалога
- `/reset` — очистить память и начать диалог заново

## Запуск в облаке через Railway (удобно с телефона, без терминала)

### Шаг 1 — залей код на GitHub
1. Зайди на github.com (можно прямо с телефона), создай аккаунт если нет
2. Создай новый репозиторий: "New repository" → дай название (например `my-ai-bot`) → Create
3. На странице репозитория: "Add file" → "Upload files" → выбери ВСЕ файлы из этой папки
   (кроме `venv/`, его не нужно — там его и нет, он локальный)
4. Внизу нажми "Commit changes"

### Шаг 2 — подключи Railway
1. Зайди на railway.app, зарегистрируйся через GitHub (кнопка "Login with GitHub")
2. "New Project" → "Deploy from GitHub repo" → выбери свой репозиторий
3. Railway сам увидит `requirements.txt` и `Procfile`, установит зависимости и запустит бота

### Шаг 3 — впиши ключи (ключевой момент!)
В проекте на Railway: вкладка **Variables** → добавляешь по одной:
```
BOT_TOKEN = токен от @BotFather
GEMINI_API_KEY = твой ключ Gemini
MISTRAL_API_KEY = твой ключ Mistral
GPTOSS_API_KEY = твой ключ GPT-OSS (OpenRouter/Groq)
GPTOSS_BASE_URL = https://openrouter.ai/api/v1
```
**В файле `config.py` НИЧЕГО менять не нужно** — код сам подхватывает эти переменные
через `os.getenv(...)`. Заглушки в коде ("ВСТАВЬ_GEMINI_KEY" и т.п.) — это просто дефолт
на случай, если забудешь задать переменную, реальные ключи туда вписывать не надо.

### Шаг 4 — проверь, что бот запустился
Во вкладке **Deployments** → открой последний деплой → там будут логи. Если увидишь
"Бот запущен" — всё ок, иди в Telegram и пиши /start своему боту.

### Если что-то меняешь в коде потом
Просто загружаешь изменённый файл заново на GitHub (Upload files, тем же именем,
подтверждаешь замену) — Railway сам увидит изменение и передеплоит бота автоматически.

## Запуск локально (для теста на компьютере)

```bash
python3 -m venv venv
source venv/bin/activate       # на Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка ключей

Открой `config.py` и впиши свои ключи напрямую, либо (рекомендуется) задай переменные окружения:

```bash
export BOT_TOKEN="токен от @BotFather"
export GEMINI_API_KEY="твой ключ"
export MISTRAL_API_KEY="твой ключ"
export GPTOSS_API_KEY="твой ключ"          # ключ от OpenRouter/Groq и т.п.
export GPTOSS_BASE_URL="https://openrouter.ai/api/v1"   # или другой провайдер
```

Список моделей для ротации задаётся прямо в `config.py` (можно менять состав/порядок):
```python
GEMINI_MODELS = ["gemini-2.0-flash", "gemini-2.0-flash-exp", "gemini-1.5-pro"]
MISTRAL_MODELS = ["mistral-large-latest", "mistral-small-latest"]
```

## Запуск

```bash
python bot.py
```

Бот запустится в режиме polling — просто найди его в Telegram и напиши /start.

## Важные нюансы

1. **GPT-OSS-120B** — сам по себе не имеет единого официального API, обычно доступен
   через агрегаторы (OpenRouter, Groq, Together AI). Впиши правильный `GPTOSS_BASE_URL`
   под своего провайдера.
2. **Генерация изображений через Gemini** — модель `gemini-2.0-flash-exp-image-generation`
   может быть переименована/обновлена, проверь актуальное название в документации Google
   AI Studio, если начнёт выдавать ошибку.
3. **Excel-режим** — бот просит модель ответить строго в JSON, затем сам собирает таблицу
   через openpyxl. Если модель ответит "не по формату" — попробует переформулировать запрос.
4. **Память** — теперь хранится в SQLite (`memory.db`, создаётся автоматически рядом
   с ботом), переживает перезапуск. Хранит последние 30 сообщений на чат — при желании
   поменяй `MAX_MESSAGES` в `memory.py`.
5. Ротация сейчас работает МЕЖДУ моделями одного провайдера (3 Gemini, 2 Mistral) и
   МЕЖДУ провайдерами. Ротацию нескольких ключей ОДНОГО и того же провайдера (например,
   5 разных API-ключей от GPT-OSS) можно добавить отдельно — сейчас у каждого провайдера
   один ключ. Если понадобится — допишем.
